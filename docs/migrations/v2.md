# Migrating to v2

The v2 compatibility baseline records changes that shipped during the 1.x
series without a major-version signal. Keep existing releases and tags as
published; this guide explains the current configuration and `/api/data`
contracts.

## Move non-secret settings to `config.yaml`

In v1.17, the project introduced `config.yaml` for non-secret settings but
continued to honor environment variables and values in `.env` as overrides.
Starting with v1.22, the admin UI made `config.yaml` the only source for
non-secret settings. Environment variables no longer override those values.

Move every non-secret setting into `config.yaml`, using the lowercase option
names from the [configuration table](../../README.md#options). For example:

```yaml
source: webscorer
race_id: "453854"
refresh_interval: 10
show_demographics: true
```

The former environment-variable names map to these YAML keys:

| Environment variable | `config.yaml` key |
|---|---|
| `RACE_SOURCE` | `source` |
| `WEBSCORER_RACE_ID` | `race_id` |
| `DATA_FILE` | `data_file` |
| `REFRESH_INTERVAL` | `refresh_interval` |
| `SUMMARY_DISPLAY_TIME` | `summary_display_time` |
| `SCROLL_SPEED` | `scroll_speed` |
| `SCROLL_PAUSE_TIME` | `scroll_pause_time` |
| `PINNED_LEADERS` | `pinned_leaders` |
| `SHOW_SUMMARY` | `show_summary` |
| `SHOW_OVERALL_RESULTS` | `show_overall_results` |
| `SHOW_CATEGORY_RESULTS` | `show_category_results` |
| `SHOW_DEMOGRAPHICS` | `show_demographics` |
| `PINNED_LEADERS_ON_OVERALL_RESULTS` | `pinned_leaders_on_overall_results` |
| `OVERALL_RESULTS_LAYOUT` | `overall_results_layout` |
| `DISPLAY_UNFINISHED_IN_CATEGORY` | `display_unfinished_in_category` |
| `DISPLAY_UNFINISHED_IN_OVERALL` | `display_unfinished_in_overall` |
| `CHART_BUCKET_MINUTES` | `chart_bucket_minutes` |
| `COLOR_SCHEME` | `color_scheme` |
| `SHOW_TOASTS` | `show_toasts` |

Keep only `WEBSCORER_API_ID`, `WEBSCORER_API_TOKEN`, and, when enabling the
admin page, `ADMIN_PASSWORD` in `.env` or the process environment. Secrets
remain environment-based. Settings omitted from `config.yaml` use their
built-in defaults. See [Choosing a config file](../../README.md#choosing-a-config-file)
for using a separate YAML file with `--config`.

Some older names changed before the YAML migration: `CATEGORY_PAUSE_TIME`
became `SCROLL_PAUSE_TIME`, and `SHOW_CATEGORIES` was replaced by
`SHOW_OVERALL_RESULTS` and `SHOW_CATEGORY_RESULTS`. Move those values to
`scroll_pause_time`, or to the relevant visibility keys, and remove the old
environment variables. The earlier switch from rotating result pages to
scrolling categories also replaced `PAGE_ROTATION_INTERVAL` and
`RESULTS_PER_PAGE`; `summary_display_time` controls the summary dwell, and
result categories now scroll instead of being split into a configured number
of rows. `show_lap_overview` was added after the environment overrides were
removed; set it in YAML rather than expecting a `SHOW_LAP_OVERVIEW` environment
variable to apply.

## `/api/data` compatibility

PR #74 changed racer rows to a dashboard-focused projection. Rows retain
`Place`, `Bib`, `Name`, `Time`, `TeamName`, `Category`, and `Gender`, with
`CategoryPlace` on applicable Overall rows. Fields from the raw WebScorer
records, including `Email`, `LapTimes`, and `ChipId`, are not included.

PR #81 removed `config_restart_required`. The current response includes
`config_version`, `race_generation`, and `race_selection_required` for
configuration changes and race selection; consult the README for their
meanings. If an external consumer depends on fields removed by either change,
update it to use the current response contract.

## Race Control additions

PR #94 added an **Unfinished** filter for racers who are On course or Not
started, and an **All** distance view that combines Overall racers while
showing each racer's distance. Places remain specific to each distance; the
combined view does not rank racers across distances. These features shipped
in v1.30.2 under a `fix:` commit label and are recorded here as functionality.
